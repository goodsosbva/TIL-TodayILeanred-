# 코드 흐름 색인

이 파일은 기능별 상세 설명으로 이동하기 위한 색인입니다. 자세한 그림과 구현 설명은 각 기능 문서에 나눠 넣었습니다.

## 어디를 보면 되는가

```text
앱 전체 구조          -> 00_전체_흐름.md
.env와 설정           -> 01_환경설정.md
회원가입과 메일       -> 02_회원가입_메일_Celery.md
로그인과 JWT          -> 03_로그인_JWT.md
TIL CRUD와 태그       -> 04_TIL_앱_기능.md
요청 로깅             -> 05_로깅.md
DB와 마이그레이션     -> 06_DB_마이그레이션.md
실행 curl             -> 07_curl_예시.md
```

## 전체 호출 순서 한 줄 요약

```text
HTTP 요청 -> Controller -> Service -> Repository -> DB -> Response
```

## 비동기 메일 호출 순서 한 줄 요약

```text
UserService -> Celery task.delay -> Redis -> Celery worker -> EmailService -> Gmail SMTP
```

## 인증 필요한 TIL 요청 한 줄 요약

```text
Authorization token -> get_current_user -> current_user.id -> NoteService -> NoteRepository(user_id 조건)
```

## 로깅 한 줄 요약

```text
HTTP 요청 -> logging_middleware -> user_context 저장 -> API 실행 -> logger.info -> context reset
```
