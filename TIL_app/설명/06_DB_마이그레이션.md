# DB와 마이그레이션

이 문서는 DB 모델과 Alembic 마이그레이션이 어떤 흐름으로 동작하는지 설명합니다.

## 관련 파일

```text
database.py
database_model.py
migrations/env.py
migrations/versions/5081832f5d2c_add_user_table.py
migrations/versions/8b2f6c1d4e90_add_note_tables.py
user/infra/db_models/user.py
note/infra/db_models/note.py
```

## 1. DB 연결 코드 흐름

```mermaid
flowchart TD
    A[.env DATABASE_*] --> B[config.get_settings]
    B --> C[database.py]
    C --> D[SQLALCHEMY_DATABASE_URL 생성]
    D --> E[create_engine]
    E --> F[SessionLocal]
    F --> G[Repository에서 with SessionLocal 사용]
```

`database.py`

```python
SQLALCHEMY_DATABASE_URL = (
    "mysql+pymysql://"
    f"{settings.database_username}:{settings.database_password}"
    f"@{settings.database_host}:{settings.database_port}/{settings.database_name}"
)
```

DB 접속 정보는 전부 `.env`에서 옵니다.

## 2. Repository에서 DB를 쓰는 흐름

```mermaid
sequenceDiagram
    participant Service
    participant Repo
    participant Session as SessionLocal
    participant DB

    Service->>Repo: save/find/update/delete 요청
    Repo->>Session: with SessionLocal() as db
    Session->>DB: query/add/delete/commit
    DB-->>Session: 결과
    Session-->>Repo: ORM model
    Repo-->>Service: domain object
```

## 3. Alembic 마이그레이션 흐름

```mermaid
flowchart TD
    A[alembic upgrade head] --> B[migrations/env.py]
    B --> C[database.SQLALCHEMY_DATABASE_URL]
    C --> D[DB 연결]
    D --> E[versions 파일 순서대로 실행]
    E --> F[user/note/tag/note_tag 테이블 생성]
```

## 4. 모델 등록

`database_model.py`

```python
import note.infra.db_models.note
import user.infra.db_models.user
```

Alembic이 SQLAlchemy metadata를 알 수 있게 모델을 import합니다.

## 5. 테이블 관계 그림

```mermaid
erDiagram
    user ||--o{ note : owns
    note ||--o{ note_tag : has
    tag ||--o{ note_tag : has

    user {
        string id PK
        string name
        string email
        string password
        text memo
        datetime created_at
        datetime updated_at
    }

    note {
        string id PK
        string user_id
        string title
        text content
        string memo_date
    }

    tag {
        string id PK
        string name
    }

    note_tag {
        string note_id PK
        string tag_id PK
    }
```

## 6. 실행 명령

```bash
.venv/Scripts/alembic.exe upgrade head
```

## 7. 주의점

- 모델을 만들고 `database_model.py`에 import하지 않으면 Alembic metadata에 안 잡힐 수 있습니다.
- DB 접속 정보가 틀리면 `alembic upgrade head`에서 실패합니다.
- 현재 TIL 테이블 마이그레이션 head는 `8b2f6c1d4e90_add_note_tables.py`입니다.
